El Arsenal del Trafficker AI,
corriendo en tu Claude Code

Copia los 2 comandos, pégalos en Claude Code y en menos de 2 minutos tienes la metodología completa dentro de tu terminal. Sin cuenta de GitHub. Las skills nuevas te llegan solas.

1

Agrega el marketplace

Abre Claude Code en cualquier carpeta de tu computadora y pega esta línea:

/plugin marketplace add https://github.com/CapiMario14/arsenal-trafficker-ai.git
2

Instala el arsenal

En cuanto se agregue el marketplace, corre:

/plugin install arsenal-trafficker-ai@jungla-de-los-ads
¿Te sale una versión vieja o no ves una skill nueva? Actualiza el marketplace con esta línea y listo:
/plugin marketplace update jungla-de-los-ads

¿No tienes Claude Code? Revisa el módulo de Claude Code dentro de la comunidad en Skool.
